# Package index

## All functions

- [`Ancestry_barchart()`](https://kfarleigh.github.io/PopGenHelpR/reference/Ancestry_barchart.md)
  : Plot an ancestry matrix for individuals and(or) populations.

- [`Differentiation()`](https://kfarleigh.github.io/PopGenHelpR/reference/Differentiation.md)
  : A function to estimate three measures of genetic differentiation
  using geno files, vcf files, or vcfR objects. Data is assumed to be
  bi-allelic.

- [`Fst_dat`](https://kfarleigh.github.io/PopGenHelpR/reference/Fst_dat.md)
  : A genetic differentiation matrix and locality information for each
  population. This data was generated by subsetting data of Farleigh et
  al., 2021.

- [`Het_dat`](https://kfarleigh.github.io/PopGenHelpR/reference/Het_dat.md)
  : A data frame of hypothetical heterozygosity data produced by
  Heterozygosity.

- [`Heterozygosity()`](https://kfarleigh.github.io/PopGenHelpR/reference/Heterozygosity.md)
  : A function to estimate seven measures of heterozygosity using geno
  files, vcf files, or vcfR objects. Data is assumed to be bi-allelic.

- [`HornedLizard_Pop`](https://kfarleigh.github.io/PopGenHelpR/reference/HornedLizard_Pop.md)
  :

  A population assignment data frame to be used in `Heterozygosity` and
  `Differentiation`.

- [`HornedLizard_Pop`](https://kfarleigh.github.io/PopGenHelpR/reference/HornedLizard_VCF.md)
  :

  A vcfR object to be used in `Heterozygosity` and `Differentiation`.

- [`Network_map()`](https://kfarleigh.github.io/PopGenHelpR/reference/Network_map.md)
  : A function to map statistics (i.e., genetic differentiation) between
  points as a network on a map.

- [`PCA()`](https://kfarleigh.github.io/PopGenHelpR/reference/PCA.md) :
  A function to perform principal component analysis (PCA) on genetic
  data. Loci with missing data will be removed prior to PCA.

- [`Pairwise_heatmap()`](https://kfarleigh.github.io/PopGenHelpR/reference/Pairwise_heatmap.md)
  : A function to plot a heatmap from a symmetric matrix.

- [`Piechart_map()`](https://kfarleigh.github.io/PopGenHelpR/reference/Piechart_map.md)
  : Plot a map of ancestry pie charts.

- [`Plot_coordinates()`](https://kfarleigh.github.io/PopGenHelpR/reference/Plot_coordinates.md)
  : A function to plot coordinates on a map.

- [`Point_map()`](https://kfarleigh.github.io/PopGenHelpR/reference/Point_map.md)
  : A function to map statistics as colored points on a map.

- [`Private.alleles()`](https://kfarleigh.github.io/PopGenHelpR/reference/Private.alleles.md)
  : A function to estimate the number of private alleles in each
  population.

- [`Q_dat`](https://kfarleigh.github.io/PopGenHelpR/reference/Q_dat.md)
  : A list representing a q-matrix and the locality information
  associated with the qmatrix
