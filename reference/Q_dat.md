# A list representing a q-matrix and the locality information associated with the qmatrix

List with two elements

## Usage

``` r
data(Q_dat)
```

## Format

A list with two elements:

- Qmat:

  A q-matrix with 6 columns and 30 rows, the first column lists the
  sample name and the remaining 5 represent the contribution a genetic
  cluster to that individuals ancestry

- Loc_dat:

  The locality information for each individual in the q-matrix

## Source

Data was generated by package authors.

## Examples

``` r
# \donttest{
data(Q_dat)
Qmat <- Q_dat[[1]]
rownames(Qmat) <- Qmat[,1]
Loc <- Q_dat[[2]]
Test_all <- Ancestry_barchart(anc.mat = Qmat, pops = Loc, K = 5,
```
